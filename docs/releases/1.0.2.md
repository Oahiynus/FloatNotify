# 浮笺 FloatNotify 1.0.2

**Windows x64 · 开发者 Oahiynus**

这一版可以同时保留多条 Codex 对话的提醒。一个任务完成后，另一条对话即使接着提问或请求审批，你仍能看到第一个任务的名字，也能决定先处理哪一条。

## 多张提醒如何排列

- **完成卡保留完整位置。** 中央有空位时，新卡优先居中。已有完成卡时，后来的提醒会寻找其他位置。把一张卡拖开，中央的空位就能留给下一条提醒。
- **问答和审批可以翻到前面。** 空间紧张时，两类卡片向右下方错开，露出标题和对话名。点标题即可展开对应卡片。放不下的提醒归入屏幕下方的「还有 N 条」，点开后可以按对话选择。
- **输入中的草稿保留在原处。** 新提醒到达时会避开正在输入或已经拖开的卡片。在其他应用里打字时，新出现的卡片也会保留原窗口的键盘焦点。
- **每个请求独立处理。** 两条对话问了同一个问题，提交其中一条的答案只会收起对应卡片。多条审批同时等待时，各自接收自己的允许或拒绝决定。
- **折叠和遮挡时减少后台工作。** 尚未显示的折叠提醒按需创建窗口。被遮住的卡片暂停背景采样和原题轮询，翻到前面后恢复。

项目首页的 README 提供多卡示例、安装步骤和首次接入 Codex 的说明。

## 校验安装包

将下面两个附件下载到同一目录。

| 文件 | 用途 |
| --- | --- |
| `FloatNotify-1.0.2-windows-x64-Setup.exe` | Windows x64 当前用户安装包 |
| `FloatNotify-1.0.2-windows-x64-Setup.exe.sha256` | 安装包的 SHA-256 校验文件 |

在下载目录打开 PowerShell，执行以下命令。输出的 `Hash` 应与下方数值及校验文件中的第一列一致，英文字母大小写等价。

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\FloatNotify-1.0.2-windows-x64-Setup.exe'
```

```text
ef632d4ac1da0391ad12d03f5840eefc0b46977962bd0690a74414639549fa45
```
