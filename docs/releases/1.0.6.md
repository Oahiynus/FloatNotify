# 浮笺 FloatNotify 1.0.6

**Windows x64 · 开发者 Oahiynus**

## 在浮笺内下载安装更新

安装 v1.0.6 后，可以直接在浮笺内获取后续正式版。打开「通用设置 → 关于」，点击「检查更新」。发现新版后，可以点「版本说明」先看改动，也可以直接点「更新并重启」。浮笺会下载该版的 Windows x64 安装包和校验文件，核对 SHA-256。校验通过后，浮笺会在原安装目录完成更新并重新打开。

## 从 v1.0.5 首次升级

在 v1.0.5 正式版中，进入「通用设置 → 关于」并点击「检查更新」，再点「查看新版」打开 GitHub 发布页。下载 `FloatNotify-1.0.6-windows-x64-Setup.exe` 和同名的 `.sha256` 文件。核对哈希后，双击安装包，在原安装目录完成升级。

## 校验安装包

将两个文件放在同一目录，在该目录打开 PowerShell，运行以下命令。输出应与校验文件第一列一致，字母大小写可忽略。

```powershell
(Get-FileHash -Algorithm SHA256 -LiteralPath '.\FloatNotify-1.0.6-windows-x64-Setup.exe').Hash
```

## 卡片外观

审批、问答和完成卡片沿用 v1.0.5 正式版的「液态玻璃」和「毛玻璃」，两种材质仍可在「弹窗外观」中切换。
