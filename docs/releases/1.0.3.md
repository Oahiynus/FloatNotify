# 浮笺 FloatNotify 1.0.3

**Windows x64 · 开发者 Oahiynus**

本版修复了浮笺重启后丢失 Codex 连接验证结果的问题。现在可以在客户端页连接或断开 Codex 提醒，安装器也支持在原目录补全 Windows 安装登记。本版同时包含同名对话问答卡的发送修复。

## Codex 连接与验证

- 审批、问答和完成提醒分别在收到对应的真实事件后记录验证结果。重启浮笺或修改外观等无关设置后，记录会保留。如果某类提醒依赖的 Hook 或处理逻辑发生变化，只需重新验证受影响的类型。预览和试弹不会计入验证。
- 「客户端」页顶部显示当前客户端的图标、名称和连接状态。在 Codex 页打开「启用 Codex 提醒」，浮笺会添加本次安装的审批和完成 Hook，并监听提问。关闭开关会移除这两个 Hook，保留其他 Hook 和三类提醒各自的开关选择。若提示需要信任，请到 Codex 的「设置 → Hooks」确认。
- 在「连接状态」可以看到哪些提醒还在等待真实事件。各类提醒的验证时间可在「通用设置」的诊断信息中查看。

## 在原目录补全 Windows 安装登记

如果原目录已有浮笺，但 Windows「已安装的应用」里找不到它，运行安装包并选择原目录即可。安装器会核对已有程序，补全卸载登记和开始菜单入口。个人设置和提醒历史会保留。

## 在同名对话中发送答案

例如，两条对话都叫「整理星图」。第一条发来问题后，你可以在浮笺卡片上选好答案。

- **正在查看第一条对话**时，点「发送」即可提交。
- **正在查看另一条同名对话**时，点「打开原题并发送」。浮笺会保留你选好的答案，回到发题对话，核对题目后再提交。

浮笺在读取题目和提交答案前，都会优先核对窗口对应的对话编号。取不到编号时，只有标题唯一且完全匹配才按标题定位。

## 校验安装包

将 `FloatNotify-1.0.3-windows-x64-Setup.exe` 与 `FloatNotify-1.0.3-windows-x64-Setup.exe.sha256` 放在同一目录，在 PowerShell 中运行下方命令。输出值应与校验文件第一列一致，字母大小写可忽略。

```powershell
(Get-FileHash -Algorithm SHA256 -LiteralPath '.\FloatNotify-1.0.3-windows-x64-Setup.exe').Hash
```
