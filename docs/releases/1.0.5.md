# 浮笺 FloatNotify 1.0.5

**Windows x64 · 开发者 Oahiynus**

## 修复原位升级时的偶发退出崩溃

在原安装目录升级时，安装器会先请后台运行的浮笺退出。如果浮笺此时正在检查审批请求，或正在确认完成提醒对应的对话是否在前台，退出时偶尔会崩溃。1.0.5 会先取消等待，让正在进行的界面任务收尾，再关闭窗口。

这项修复从 1.0.5 版浮笺启动后生效。首次从旧版升级到 1.0.5 时，安装器请退出的仍是当时运行的旧版。

## 校验安装包

将 `FloatNotify-1.0.5-windows-x64-Setup.exe` 和 `FloatNotify-1.0.5-windows-x64-Setup.exe.sha256` 放在同一目录。在该目录打开 PowerShell，运行下方命令，将输出与校验文件第一列比对，字母大小写可忽略。

```powershell
(Get-FileHash -Algorithm SHA256 -LiteralPath '.\FloatNotify-1.0.5-windows-x64-Setup.exe').Hash
```

本版 Windows x64 安装包的 SHA-256 为 `41d083a2338938595fb76a2cb75a1e60392c8eb0886496bd6efc93721365e56b`。
