# 浮笺 FloatNotify 1.0.4

**Windows x64 · 开发者 Oahiynus**

## 手动检查更新

打开浮笺的「通用设置 → 关于」，点击「检查更新」。浮笺只在你点击时查询 GitHub 上的最新正式版，并与当前安装的版本比较。

如果发现新版，点击「查看新版」即可在默认浏览器打开对应的发布页，阅读更新说明并自行下载安装包。如果已是最新正式版，设置页会显示提示。离线或连接超时时，可以稍后再次点击「检查更新」。

## 校验安装包

将 `FloatNotify-1.0.4-windows-x64-Setup.exe` 和 `FloatNotify-1.0.4-windows-x64-Setup.exe.sha256` 放在同一目录。在该目录打开 PowerShell，运行下方命令，将输出与校验文件第一列比对，字母大小写可忽略。

```powershell
(Get-FileHash -Algorithm SHA256 -LiteralPath '.\FloatNotify-1.0.4-windows-x64-Setup.exe').Hash
```
